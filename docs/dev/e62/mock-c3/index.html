Makieta: gaśnięcie kurtyny i powrót przy Monocubie

Storyboard SB-C3 zatwierdzony z dwiema zmianami. Tu ruch na żywo: odtwórz, przewiń, naciśnij Esc, włącz ograniczone animacje. Czasy są te z SB-C3. Dźwięk gaśnięcia jest zaślepką: wiersz "Gaśnięcie" w oknie Sound, domyślnie plik "death"; tutaj tylko ton testowy, jeśli go włączysz.

To nie jest Foundry. Obrazy to prawdziwe klatki glass harness (ekran gracza, 1366x768) i obrysy szyb z glass.mjs; animację składa ta strona na canvasie, z czasami ze specyfikacji. Puls jest tu nieruchomy. Twoja druga zmiana (martwy jako obserwator z tokenem, który przy Monocubie staje się Monocubem) czeka na Twoje odpowiedzi i nie jest w tej makiecie.

In English

A live mockup composed on a canvas from real glass-harness frames (a player's screen, 1366x768) and glass.mjs's own pane outlines, with SB-C3's timings: the death fade 3.6 s (five batches outside in, each flickering once, the edges last) and the Monocub return 2.4 s (edges, pulse, then the batches in reverse). Esc, reduced motion and the table's sequences switch jump to the end state; pulse off leaves only the edges flickering. The fade's new sound row is a stub (a test tone, off by default). The pulse is static here. Not Foundry. The owner's second note (the dead becoming a Spectator whose token turns into the Monocub) waits for the owner's answers and is not in this mockup.
