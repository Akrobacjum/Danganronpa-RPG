(wiersz Observe bez wyniku), `TIMING.gmStoreOpenMs` 16000 ms (Analyze czeka na otwarcie magazynów GM-a),
`TIMING.searchTokenAckMs` i `TIMING.plantRequestMs` po 5000 ms, `TIMING.plantWindowMs` 120000 ms; `RESENDS` = 3
(bridge-guards.mjs:2140).
