# Ślepe oczekiwania - perspektywa gracza

Napisane 24.11.2026 wyłącznie na podstawie `docs/dev/v2/BLIND-INPUT.md`, znajomości gatunku Danganronpa, doświadczenia
graczy RPG i ogólnej wiedzy o Foundry VTT. Autor nie widział kodu modułu, handbooków ani interfejsu. To, czego gracz by
się spodziewał, a nie opis tego, co moduł robi.

Perspektywy: żywy uczeń (w tym gracz, który potajemnie jest zabójcą, pomocnikiem, ofiarą albo świadkiem) i gracz,
którego uczeń zginął i który zostaje przy stole jako widz.

Ważność: **musi** - bez tego gra jest niezrozumiała, niesprawiedliwa albo zdradza tajemnicę; **powinno** - brak będzie
odczuwalny i wymusi pytania do GM-a; **miło** - poprawia wczucie, ale stół poradzi sobie bez tego.
