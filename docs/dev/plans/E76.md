### 2.2 Daggerheart's relay, 2.10.11 -> 2.12.8

`module/systemRegistration/socket.mjs` is byte-identical from 2.10.11 through 2.12.4 (sha1 prefix 59fbfd4bd9) and changes in
**2.12.5** (89f7472022, unchanged to 2.12.8). The whole diff:

```diff
             case GMUpdateEvent.UpdateSaveMessage:
                 const message = game.messages.get(data.data.message);
-                if (!message) return;
+                if (!message || !data.data) return;
+
                 game.system.api.fields.ActionFields.SaveField.updateSaveMessage(
-                    data.data.result,
+                    data.data.saveTotal,
+                    data.data.isCritical,
                     message,
                     data.data.token
                 );
```

The sender changed with it (`module/documents/chatMessage.mjs` `onRollSave`, 2.12.8:262-290): the packet now carries
`{ action, message, token, saveTotal, isCritical }` where 2.10.11 sent `{ action, message, token, result }`.

**Consequence, read in the code (not run):** `relay-guard.mjs` `judgeSave` (:816-842) reads `inner.result?.roll?.total`;
on 2.12.5+ that is undefined, so a player's save is dropped as "a save with no roll in it" (:828-829) and never marked on
the card. And when it does forward, it forwards `result: {...}`, which 2.12.5+'s handler no longer reads. The case list
and the `default:` branch did not change, so `fingerprintOf` (:277) still reads "ok": **the fingerprint does not see this
change**. This is the first concrete fix of the stage.
