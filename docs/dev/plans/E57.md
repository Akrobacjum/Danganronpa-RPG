## 3. Boundary with E25 and E71

E57 edits the handbooks, the guards and the D34 and D35 code; it does not edit a UI key, except a key D34 or D35 adds
(the "?" tooltip, the setting's empty choice). The UI is E71's finished state: a handbook sentence that names a button
is made to match the button, never the reverse; a UI fault found now goes to the ledger as a carried item. E25's
handbook corrections are input to the facts inventory, and E57 then rewrites the form of every paragraph once.
