## 6. Risks

- A rule after merging can win for another reason (specificity, layer); the snapshot compares computed values, but a
  surface not on STYLE_SURFACES passes with a regression (the audit's risk). E59 looks at everything by eye.
- The split changes the order of sheets in the cascade; a theme rule that wins over narrow.css's stack would break the
  narrow layout (A7). The split is last, after the snapshot is clean.
- jsdom's cascade has no `@media` and no layers: every number in this stage is Chromium's, from the sweeps.
