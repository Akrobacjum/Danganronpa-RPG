# The tooltip sweep (1.2.115): the list

Every site the census (tools/tooltip-census.mjs) counted with neither a tooltip nor a hint line on 9e7e3d78 (1.2.114): 242 sites, 241 rows of tools/tooltip-census.json. The 224 rows E102 left as "none needed" were each read against the code that draws and runs the control, one agent per screen family, 14.11.2026; the 17 rows of "help in code" and "conditional" E102 wrote stay as they were and are listed last. Columns: the window as drawn, the control, what it does (read from the code), today's label (English), the reader, and what it has now - a tooltip (its English words; the Polish are in lang/pl.json under the same key), a hint, "label is enough" or "not met", with the reason. The census key is the label key the census read near the control; where the agents found it is a neighbour's, the note says so.

Counts: tooltip 174 rows (208 keys; some rows draw several controls from one helper), hint 36, help in code 2 (the census cannot follow the markup), label is enough 9, not met 4. After the sweep the census reads 70 sites with no tooltip and no hint line near, every one a row with its reason.
