New tier pool

A tier pool is named for its category and its tier, as “DRPG Tools - Tier 2” is. Usually you do not make one by hand: “Install / reinstall” below builds them all.

The tables live in the Rollable Tables sidebar, in the “Danganronpa RPG” folder. A Search in a room draws from that room's own tables first, then from the tier pools, then from the module's built-in lists. “Install / reinstall” below builds the default set - one table per category and tier. If they already exist, you choose between keeping yours and rebuilding.

New room table

A room table is what a room stocks - point a room at it in Room Setup's “Draws from”. Tier tables answer dice rolls and cannot be assigned to rooms. A room's own tables answer a Search there before the tier pools do, and one named “«Room» - Tier N” answers that roll first.
